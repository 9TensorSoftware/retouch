AI, on your device

AI that never sees a server.

Each model downloads once, then runs on your device. Everything below came from Rétouch's own models, and the first two will run again right here if you ask.

Detect

      For developers

      Drop it into your own app.

      A TypeScript library for any framework, with plugins and theming.

      $ npm i @9tensor/retouch
      • Read the docs
      • Write a plugin
      • Theme it
      import { Retouch } from "@9tensor/retouch";
import { installMlTools } from "@9tensor/retouch-ml";

const retouch = new Retouch({
  target: "#editor",
  theme: "auto",
  onDone: (blobs) => upload(blobs),
});

// Optional: cutout, erase, upscale and the rest, on-device.
installMlTools(retouch);
